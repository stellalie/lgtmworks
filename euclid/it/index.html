Euclid for IT teams

Someone at your company asked to use Euclid. This page is what you need to review it.

Euclid is a launcher for macOS: one shortcut to open apps, find files and projects, and paste earlier clipboard entries and snippets. It runs on the Mac, with no account and no cloud service.

The app

  • Publisher: LGTM Ninja, Sydney, Australia. Contact hello@lgtm.ninja.
  • Bundle ID: dev.euclid.Euclid, installed as Euclid.app.
  • Signed and notarized: signed with an Apple Developer ID certificate and notarized by Apple.
  • Native: Swift and AppKit. No Electron, no web views, no bundled runtime.
  • Install: a standard DMG. It runs from /Applications or from the user's own ~/Applications.

Network

Euclid works with the network unplugged. These are all the connections it makes:

  • Update check, daily: github.com/stellalie/euclid-bar-releases (Sparkle feed). Turn it off with [updates] check = false.
  • Crash reports, only if the user says yes: reports.lgtm.ninja. Off unless chosen; a copy of each is kept in ~/Library/Logs/Euclid/Reports.
  • Usage ping, only if the user says yes: reports.lgtm.ninja, once a day, a random install ID plus app and macOS version.
  • Plugins and actions the user adds (for example a Jira plugin) connect only to the services they name, from the Mac, with the user's own credentials.
  • No analytics, no advertising, no built-in AI service. The licence is checked offline.

Data on the Mac

  • ~/Library/Application Support/Euclid: clipboard history, search index and learned rankings. Never uploaded.
  • ~/.config/euclid: the user's settings, scripts and plugins, as plain text.
  • Copies from 1Password and other password managers are never recorded. More apps can be excluded with [clipboard] ignore_apps.

Permissions

All optional. Search, hotkeys and the clipboard list work without any of them.

  • Accessibility: to paste a clip or snippet into the app in front, and for text expansion. Without it, Euclid copies and the user pastes.
  • Full Disk Access: only to search Safari history.

Configuration you can manage

  • Everything is in one text file, ~/.config/euclid/config.toml. Each feature is one line that can be turned off.
  • include = ["/path/to/company.toml"] reads a shared file underneath the user's own, so you can ship company defaults.
  • [history] enabled = false, [updates] check = false and [privacy] switch off browser history, update checks and reporting.
