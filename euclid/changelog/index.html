1.3.1 1 Nov 2026

  • Opens at login. Your hotkey works right after a restart. Switch it off in the menu bar icon or with [startup] open_at_login = false.
  • A welcome on first launch. The panel opens once and shows your hotkey, instead of starting silently in the menu bar.
  • Asked, not assumed. First launch asks once about crash reports and an anonymous daily usage ping. Both start unticked.
  • Cut the Raycast and Alfred import. Fewer features, done well.
Download 1.3.1

1.3.0 31 Oct 2026

  • AI answers in the bar. The ai plugin uses Apple's on-device model by default, or the AI CLI you're already logged into. No API key, no account.
  • Opt-in crash and error reports. Stack and versions only, never your data. Off unless you set [privacy] crash_reports = true.
Download 1.3.0

1.2.1 31 Oct 2026

  • Themes. 10 editor palettes (Catppuccin, Dracula, Gruvbox, Monokai, Nord, Solarized, Tokyo Night) and your own theme files: [appearance] theme.
  • Bitbucket and Jira are plugins now. Same results, off until you want them.
  • Permissions in one row. A plugin whose CLI is missing names it.
  • Speed has a budget. CI fails if a keystroke over 10k+ items takes more than 8 ms.
  • Fixed the "couldn't read Dia" history warning repeating.
  • Cut page text search, the usage receipt and mod: in the bar. Fewer features, done well.
Download 1.2.1

1.2.0 25 Oct 2026

  • Plugins. Sources, answers, badges and actions from any script. euclid-bar --plugin list shows what's on.
  • Text expansion and per-command hotkeys.
  • MCP. Claude Code and Codex can search Euclid.
  • Project tasks from ⌘K, a shared team config via include, and imports of Raycast and Alfred snippets and quicklinks.
  • New panel. Glass background (macOS 26), preview pane, snippets, image clips and notes search.
  • Signed, notarized and self-updating. Updates menu, auto-install toggle and the dev channel. The app is now Euclid.app.
