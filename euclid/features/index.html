Plugins

Add only what you use: euclid-bar --plugin add <name>. They cost nothing until you add one.

bitbucket pluginYour open PRs, PRs waiting on your review, and your repos. Cloud and Data Center
jira pluginIssues assigned to you and ones you viewed lately. Type ABC-123 to open any issue; ⇧⌘C copies a branch name
linear pluginLinear issues assigned to you
slack pluginJump to channels; slack <words> searches messages
contacts pluginPeople by name, company, email or phone
shortcuts pluginRun your Apple Shortcuts by name
define plugindefine serendipity from the macOS Dictionary
currency plugin100 usd to eur with daily rates, no API key
tokens pluginToday's Claude Code tokens and cost on the bar, from ccusage
cleanlinks pluginCopy a link and the clipboard gets it without utm_*, fbclid and other tracking junk
reveal plugin⇧⌘R on a file, project or app shows it in Finder

Actions and keys

Every action is one shell line in your config.

ActionsRun any command on what you typed. Your query arrives as $1, passed as an argument, never pasted into the command
Action shortcuts⌘↵ runs your first action, ⌘1–⌘9 run the rest
Action palette⌘K: arrow keys, numbers or type to filter
Aliasesgh swift testing runs the GitHub action on "swift testing"
No match? Ask an agentWhen nothing matches, your actions show up, so a question is one ↵ from Claude, Codex, pi or a local model
Ghosttyghostty-run opens a tab, split or window. A readable script in ~/.config/euclid/bin
Preview pane→ or ⌘Y: the full clip, images, Quick Look, a project's README, a page's text
Copy anything⌘C copies the clip, a page's URL, or a path. ⌘⌫ deletes a clip

Without opening the panel

Text expansion opt-inType a snippet's keyword in any app and it turns into the snippet. Needs Accessibility
Permissions in one placeType permissions to see what's allowed and what's missing; ↵ opens the right System Settings pane
Per-command hotkeysGive any app, project, action or snippet its own hotkey in [hotkeys]. Its row shows it
Global hotkey⌥Space by default, any combination you like
