Why Euclid

Your whole setup is one folder. Put it in git.

Everything you configure lives in ~/.config/euclid. Commit it with your dotfiles, and a new Mac is one git clone away.

~/.config/euclid/
├── config.toml  # actions, snippets, hotkeys
├── bin/         # your scripts
└── plugins/     # one folder each

$ cd ~/.config/euclid
$ git init && git add .
$ git commit -m "my euclid"
  • Review it like code. Every change is a diff you can read, revert or share in a PR.
  • No secrets in the repo. Tokens stay in the Keychain; plugins and integrations read them with a command.
  • No machine junk either. Clipboard, history, indexes and the licence live in ~/Library/Application Support/Euclid.
  • Share with your team. include a team file and point [plugins] paths at a team repo; your own settings still win.

Where your data goes

Euclid works with the network unplugged. These are the only times it goes online.

  • Update checks ask GitHub for the latest version. Turn them off with [updates] check = false.
  • The Bitbucket and Jira plugins, only if you add them, talk straight to your own server, with a token your own command fetches (Keychain, 1Password CLI).
  • Your actions do whatever their shell line says, nothing more.
  • Crash reports and a usage ping, only if you say yes (Euclid asks once): the crashed code's stack, a random install ID and versions, never your data.
  • Never sent anywhere: what you type, your clipboard, your history, your files.
  • Password managers: copies from 1Password and friends are never recorded.
  • This website counts page views with cookie-free Cloudflare Web Analytics. The app sends nothing else.

Plugins are just scripts

A folder with a plugin.toml and a script in any language that prints one JSON object per line. No SDK, no build step, no store. Save it and it's in the bar.

# ~/.config/euclid/plugins/tokens/plugin.toml
name = "Claude tokens"

[badge]                     # a chip on the search bar
run   = "./today.sh"        # prints "1.2M tok · $4.10"
refresh_minutes = 5
click = 'ghostty-run tab npx -y ccusage@latest daily'
  • [source] adds items to search, refreshed in the background.
  • [answer] replies to what you type, on a prefix or a regex.
  • [badge] puts a live status on the bar.
  • [[action]] adds commands to ⌘K.
  • Let your AI write one. The format ships as AGENTS.md: ask Claude Code or Codex, check it with --try-plugin.
