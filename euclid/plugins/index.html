Plugins

Build one with your agent

Euclid keeps the whole plugin format in ~/.config/euclid/plugins/AGENTS.md, written for coding agents. Your agent reads it, writes the folder, runs --try-plugin until it prints OK, and the plugin shows up in the bar the moment it's saved.

your agent

1. Describe what you want

2. Copy the prompt into Claude Code, Codex or any agent with a shell

The prompt points at the plugin guide, the whole format on one page. Euclid also keeps a copy at ~/.config/euclid/plugins/AGENTS.md. Agent without web access? and paste it in first.

1

Ask

Paste a prompt into Claude Code, Codex or any agent with a shell.

2

It tests itself

--try-plugin prints the exact rows or error, so the agent fixes its own mistakes.

3

It's live

Euclid watches the plugins folder and reloads on save. You don't restart anything.

Worked example: a token badge

Paste this, and a minute later the bar shows 1.2M tok · $4.10. Click it and ccusage opens in a new Ghostty tab.

Read ~/.config/euclid/plugins/AGENTS.md. Then make a Euclid plugin in
~/.config/euclid/plugins/tokens that shows today's Claude Code token use and
cost as a badge on the bar, using `npx -y ccusage@latest daily --json`.
Clicking the badge should open `ccusage daily` in a new Ghostty tab
(ghostty-run tab ...). Refresh every 5 minutes.
Run `/Applications/Euclid.app/Contents/MacOS/euclid-bar --try-plugin tokens`
and fix the plugin until it prints OK.

What the agent ends up writing:

# tokens/plugin.toml
name = "Claude tokens"

[badge]
run   = "./today.sh"
icon  = "gauge.with.dots.needle.33percent"
refresh_minutes = 5
click = 'ghostty-run tab npx -y ccusage@latest daily'
# tokens/today.sh
#!/bin/sh
set -eu
npx -y ccusage@latest daily \
    --since "$(date +%Y%m%d)" --json |
  jq -r '[.totals.totalTokens, .totals.totalCost] | @tsv' |
  awk -F '\t' '{ printf "%.1fM tok · $%.2f\n", $1/1e6, $2 }'

GitHub

Source

Your open PRs, PRs waiting on your review, and issues assigned to you. Uses the gh CLI, so there's no token to manage.

Type fix login → your PR “Fix login on Safari” with a Review label.

euclid-bar --plugin add github
How it's written · 26 lines

Every 5 minutes items.sh asks the gh CLI for your PRs and issues and prints one JSON row each.

plugin.toml

name = "GitHub"
description = "Your open PRs, PRs waiting on your review, and issues assigned to you. Uses the GitHub CLI: brew install gh && gh auth login"

[source]
run = "./items.sh"
refresh_minutes = 5

[[action]]
name = "Search GitHub code"
run  = 'open "https://github.com/search?type=code&q=$EUCLID_QUERY_URL"'

[settings]
limit = 30          # per list; override in config.toml with [plugin.github] limit = 50

items.sh

#!/bin/sh
# Prints one JSON object per line for Euclid. `gh` does the auth and the JSON (--jq).
set -eu
command -v gh >/dev/null 2>&1 || { echo "needs the GitHub CLI: brew install gh && gh auth login" >&2; exit 1; }
limit=${EUCLID_SETTING_LIMIT:-30}
row='{title, subtitle: "\(.repository.nameWithOwner) · #\(.number)", open: .url, id: .url, icon: "arrow.triangle.pull"}'

gh search prs --review-requested=@me --state=open --limit "$limit" --json number,title,url,repository \
  --jq ".[] | $row + {label: \"Review\", suggest: true} | tojson"
gh search prs --author=@me --state=open --limit "$limit" --json number,title,url,repository \
  --jq ".[] | $row + {label: \"Your PR\"} | tojson"
gh search issues --assignee=@me --state=open --limit "$limit" --json number,title,url,repository \
  --jq ".[] | $row + {label: \"Issue\", icon: \"smallcircle.filled.circle\"} | tojson"

Linear

Source

Linear issues assigned to you and not done. ↵ opens one, ⌘C copies its ID. The API key lives in the Keychain.

Type eng- → your open Linear issues, newest first.

euclid-bar --plugin add linear
How it's written · 24 lines

Every 5 minutes items.sh sends one GraphQL query with your key from the Keychain and prints a row per issue.

plugin.toml

name = "Linear"
description = "Linear issues assigned to you. Store a personal API key (Linear › Settings › Security & access) in the Keychain: security add-generic-password -s euclid-linear -a \"$USER\" -w '<key>'"

[source]
run = "./items.sh"
refresh_minutes = 5

[settings]
token_command = "security find-generic-password -s euclid-linear -w"
limit = 50

items.sh

#!/bin/sh
# Linear issues assigned to you and not done. ↵ opens the issue, ⌘C copies its ID (ENG-123).
set -eu
command -v jq >/dev/null 2>&1 || { echo "needs jq: brew install jq" >&2; exit 1; }
key=$(eval "$EUCLID_SETTING_TOKEN_COMMAND" 2>/dev/null) || key=""
[ -n "$key" ] || { echo "no Linear API key: security add-generic-password -s euclid-linear -a \"$USER\" -w '<key>'" >&2; exit 1; }
query='query($n: Int) { viewer { assignedIssues(first: $n, orderBy: updatedAt,
  filter: { state: { type: { nin: ["completed", "canceled"] } } }) {
  nodes { identifier title url state { name } team { key } } } } }'
jq -n --arg q "$query" --argjson n "${EUCLID_SETTING_LIMIT:-50}" '{query: $q, variables: {n: $n}}' |
  curl -fsS https://api.linear.app/graphql -H "Authorization: $key" -H 'Content-Type: application/json' --data @- |
  jq -c 'if .errors then error(.errors[0].message) else .data.viewer.assignedIssues.nodes[] end
         | {title, subtitle: "\(.identifier) · \(.state.name)", open: .url, id: .url, copy: .identifier,
            label: .team.key, icon: "checklist"}'

Slack

Source + answer

Jump to any channel you're in, and type slack deploy failed to search messages. Needs a user token.

Type slack deploy failed → the 10 best matching messages.

euclid-bar --plugin add slack
How it's written · 35 lines

A source lists your channels every hour; an answer runs search.sh only when you type the slack prefix.

plugin.toml

name = "Slack"
description = "Jump to your Slack channels, and search messages with `slack <words>`. Needs a user token (xoxp-) with channels:read, groups:read and search:read, in the Keychain: security add-generic-password -s euclid-slack -a \"$USER\" -w '<token>'"

[source]
run = "./channels.sh"
refresh_minutes = 60

[answer]
run    = "./search.sh"
prefix = "slack"

[settings]
token_command = "security find-generic-password -s euclid-slack -w"

channels.sh

#!/bin/sh
# Channels you're in; ↵ opens them in the Slack app.
set -eu
command -v jq >/dev/null 2>&1 || { echo "needs jq: brew install jq" >&2; exit 1; }
token=$(eval "$EUCLID_SETTING_TOKEN_COMMAND" 2>/dev/null) || token=""
[ -n "$token" ] || { echo "no Slack token: security add-generic-password -s euclid-slack -a \"$USER\" -w '<xoxp-token>'" >&2; exit 1; }
api() { curl -fsS -H "Authorization: Bearer $token" "https://slack.com/api/$1"; }
team=$(api auth.test | jq -r 'if .ok then .team_id else error(.error) end')
api "users.conversations?types=public_channel,private_channel&exclude_archived=true&limit=1000" |
  jq -c --arg team "$team" 'if .ok then .channels[] else error(.error) end
         | {title: "#\(.name)", subtitle: (.purpose.value // ""), open: "slack://channel?team=\($team)&id=\(.id)",
            id: .id, icon: (if .is_private then "lock" else "number" end)}'

search.sh

#!/bin/sh
# `slack deploy failed`: the 10 best matching messages; ↵ opens the message.
set -eu
token=$(eval "$EUCLID_SETTING_TOKEN_COMMAND" 2>/dev/null) || token=""
[ -n "$token" ] || { echo "no Slack token (see plugin.toml)" >&2; exit 1; }
q=$(jq -rn --arg q "$1" '$q | @uri')
curl -fsS -H "Authorization: Bearer $token" "https://slack.com/api/search.messages?count=10&query=$q" |
  jq -c 'if .ok then .messages.matches[] else error(.error) end
         | {title: (.text | gsub("\\s+"; " ") | .[0:140]), subtitle: "#\(.channel.name) · \(.username // "")",
            open: .permalink, id: .permalink, icon: "bubble.left", preview: .text}'

Claude tokens

Badge

Today's Claude Code tokens and cost on the search bar, from ccusage. Click it for the full report in a terminal.

Always on the bar: 1.2M tok · $4.10. Click it for the full report.

euclid-bar --plugin add tokens
How it's written · 18 lines

A badge: every 5 minutes today.sh runs ccusage, which reads Claude Code's local logs, and prints one line.

plugin.toml

name = "Claude tokens"
description = "Today's Claude Code token use and cost on the bar, from ccusage. Click it for the full report."

[badge]
run   = "./today.sh"
icon  = "gauge.with.dots.needle.33percent"
refresh_minutes = 5
click = 'ghostty-run tab npx -y ccusage@latest daily'

today.sh

#!/bin/sh
# Prints today's Claude Code usage for the badge, e.g. "1.2M tok · $4.10". Needs Node (npx) and jq.
set -eu
command -v jq >/dev/null 2>&1 || { echo "needs jq: brew install jq" >&2; exit 1; }
if command -v ccusage >/dev/null 2>&1; then set -- ccusage; else set -- npx -y ccusage@latest; fi
"$@" daily --since "$(date +%Y%m%d)" --json |
  jq -r '[.totals.totalTokens // 0, .totals.totalCost // 0] | @tsv' |
  awk -F '\t' '{ t = $1 + 0
                 s = t >= 1e6 ? sprintf("%.1fM", t / 1e6) : t >= 1e3 ? sprintf("%.0fk", t / 1e3) : t
                 printf "%s tok · $%.2f\n", s, $2 }'

Contacts

Source

People by name, company, email or phone. ↵ opens the card, ⌘C copies the email. macOS asks once for access.

Type ada → Ada Lovelace · Analytical Engines · ada@example.com.

euclid-bar --plugin add contacts
How it's written · 21 lines

A JavaScript for Automation script reads the Contacts app once an hour and prints a row per person.

plugin.toml

name = "Contacts"
description = "People in Contacts by name, company, email or phone. ↵ opens the card, ⌘C copies the email. macOS asks once for access."

[source]
run = "osascript -l JavaScript ./people.js"
refresh_minutes = 60

people.js

// Everyone in Contacts, one JSON line each. Reads whole columns at once, which is fast.
function run() {
  const people = Application('Contacts').people
  const ids = people.id(), names = people.name(), orgs = people.organization()
  const emails = people.emails.value(), phones = people.phones.value()
  return ids.map((id, i) => {
    const name = names[i] || orgs[i]
    if (!name) return null
    const email = (emails[i] || [])[0], phone = (phones[i] || [])[0]
    return JSON.stringify({
      title: name, subtitle: [orgs[i] !== name ? orgs[i] : null, email, phone].filter(Boolean).join(' · '),
      open: 'addressbook://' + id, copy: email || phone || name, id, icon: 'person.crop.circle',
    })
  }).filter(Boolean).join('\n')
}

Dictionary

Answer

Type define serendipity for the macOS Dictionary's definition. ↵ opens Dictionary, ⌘C copies it.

Type define serendipity → the definition, right in the bar.

euclid-bar --plugin add define
How it's written · 20 lines

An answer on the define prefix calls macOS Dictionary Services and prints one row.

plugin.toml

name = "Dictionary"
description = "`define serendipity`: the macOS Dictionary's definition. ↵ opens it in Dictionary, ⌘C copies it."

[answer]
run    = 'osascript -l JavaScript ./define.js "$1"'
prefix = "define"

define.js

// The definition from the dictionaries you turned on in Dictionary.app, via Dictionary Services.
ObjC.import('CoreServices')

function run(argv) {
  const word = argv.join(' ')
  const open = 'dict://' + encodeURIComponent(word)
  const ref = $.DCSCopyTextDefinition(null, $(word), $.NSMakeRange(0, word.length))
  const text = ref ? ObjC.unwrap(ObjC.castRefToObject(ref)) : ''
  if (!text) return JSON.stringify({ title: 'No definition for “' + word + '”', subtitle: 'Open Dictionary', open, icon: 'character.book.closed' })
  return JSON.stringify({
    title: text.replace(/\s+/g, ' ').slice(0, 140), subtitle: word + ' · Dictionary',
    open, copy: text, preview: text, id: open, icon: 'character.book.closed',
  })
}

Currency

Answer

Type 100 usd to eur. Daily rates from a free API, no key, cached for an hour. ↵ copies the amount.

Type 100 usd to eur → the amount in euros at today's rate; ↵ copies it.

euclid-bar --plugin add currency
How it's written · 26 lines

An answer with a regex match: convert.sh fetches free daily rates, caches them for an hour, and prints the result.

plugin.toml

name = "Currency"
description = "`100 usd to eur`: converts with daily rates from open.er-api.com (free, no key). ↵ copies the amount."

[answer]
run    = "./convert.sh"
match  = '(?i)^\d[\d,.]*\s*[a-z]{3}\s+(to|in)\s+[a-z]{3}$'
prefix = "cur"      # or `cur 100 usd eur`

convert.sh

#!/bin/sh
# Rates are cached for an hour outside this folder (writing here would reload the plugin).
set -euf
command -v jq >/dev/null 2>&1 || { echo "needs jq: brew install jq" >&2; exit 1; }
# "100usd TO eur" → 100 USD EUR
set -- $(printf '%s' "$1" | tr 'a-z' 'A-Z' | sed -E 's/,//g; s/([0-9])([A-Z])/\1 \2/; s/ (TO|IN) / /')
[ $# -eq 3 ] || { echo "try: 100 usd to eur" >&2; exit 1; }
amount=$1 from=$2 to=$3
cache="${TMPDIR:-/tmp}/euclid-rates-$from.json"
if [ ! -s "$cache" ] || [ -n "$(find "$cache" -mmin +60)" ]; then
  # Not a currency (e.g. `10 kgs in lbs`): show nothing.
  curl -fsS --max-time 1.5 "https://open.er-api.com/v6/latest/$from" > "$cache.tmp" 2>/dev/null || { rm -f "$cache.tmp"; exit 0; }
  mv "$cache.tmp" "$cache"
fi
jq -c --arg to "$to" --arg from "$from" --arg n "$amount" '
  select(.result == "success" and .rates[$to] != null)
  | ($n | tonumber) as $a | .rates[$to] as $r | ($a * $r * 100 | round / 100 | tostring) as $v
  | {title: "\($v) \($to)", subtitle: "\($n) \($from) · 1 \($from) = \($r) \($to) · \(.time_last_update_utc)",
     copy: $v, icon: "dollarsign.arrow.circlepath", label: "Currency"}' "$cache"

How plugins work

Everything is optional, but a plugin needs at least one part. The full reference is AGENTS.md in your plugins folder.

PartWhat it addsWhen it runs
[source]Items in search: PRs, deploys, runbooksIn the background, every refresh_minutes (30 s limit)
[answer]A reply to what you type, below the instant resultsOnly on its prefix or match regex (2 s limit)
[badge]A short status chip on the search bar; click runs a commandIn the background, every refresh_minutes
[[action]]Actions in ⌘K, after your ownWhen you pick one
[settings]Defaults you override in config.toml with [plugin.<id>]Passed as $EUCLID_SETTING_<KEY>

A script prints rows

One JSON object per line. Only title is required. ↵ does the first of open, paste, copy or run that's set. Add "suggest":true to show a row when the box is empty.

{"title": "Fix login on Safari",
 "subtitle": "acme/web · #412",
 "open": "https://github.com/acme/web/pull/412",
 "label": "Review",
 "icon": "arrow.triangle.pull",
 "suggest": true}
  • Any language. Scripts run in your login shell inside the plugin folder, so Homebrew tools are on your PATH.
  • Safe with your input. What you type only reaches a script as $1 and $EUCLID_QUERY. It's never pasted into a command.
  • Never slows typing. Plugin results land below the instant ones, and a slow script is stopped at its time limit.
  • Secrets stay out of files. Read tokens from the Keychain in the script (security find-generic-password), the same way the bitbucket and jira plugins do.

Share one

A plugin is a folder, so a git repo is all it takes to share one. Anyone installs it with --plugin add <git URL>, and Euclid prints the commands it runs so they can read them first.

A team can keep its plugins in a shared repo and point everyone's config at it. Pulling the repo reloads them.

Built something useful? and it may land in the directory.

# ~/.config/euclid/config.toml
[plugins]
paths    = ["~/work/team/euclid-plugins"]
disabled = ["tokens"]

[plugin.github]        # your values for its settings
limit = 50

Plugins run as you, like your actions do, so read a plugin before you add it.

  1. Copy an action below.
  2. Paste it at the end of ~/.config/euclid/config.toml and save. Euclid picks it up straight away.
  3. Use it: type something and run it any of the ways below.

Four ways to run an action

  • ⌘K Action list. Type your words, press ⌘K, pick one with the arrows or its number. Works for every action.
  • ⌘↵ ⌘1–⌘9 By position. Actions keep the order they have in your config: the first one is ⌘1 and ⌘↵, the second ⌘2, and so on. Put your favourite first.
  • No match? They're already there. When nothing matches what you typed (usually a question), your actions fill the list, so ↵ runs the first one. That's why the AI agent actions don't need an alias.
  • alias A word that runs it directly. Add alias = "gh" and typing gh swift testing + ↵ runs that action on “swift testing”, skipping the list. Worth it for lookups you do every day; cards with one show an alias tag.

Want one from anywhere, without opening Euclid? Give it a hotkey = "ctrl+opt+g" too; it runs with an empty query.

What you typed reaches the command as $1, or URL-encoded as $EUCLID_QUERY_URL. It's passed as an argument, so it can't run anything by itself. Made a good one?
