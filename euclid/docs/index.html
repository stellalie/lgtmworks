Where your data goes

Euclid works with the network unplugged. These are the only times it goes online.

  • Update checks ask GitHub for the latest version. Turn them off with [updates] check = false.
  • The Bitbucket and Jira plugins, only if you add them, talk straight to your own server, with a token your own command fetches (Keychain, 1Password CLI).
  • Your actions do whatever their shell line says, nothing more.
  • Crash reports and a usage ping, only if you say yes (Euclid asks once): the crashed code's stack, a random install ID and versions, never your data.
  • Never sent anywhere: what you type, your clipboard, your history, your files.
  • Password managers: copies from 1Password and friends are never recorded.
  • This website counts page views with cookie-free Cloudflare Web Analytics. The app sends nothing else.

Command line

The app's binary: /Applications/Euclid.app/Contents/MacOS/euclid-bar. Alias it as euclid-bar.

--check-configChecks config.toml and every included file, theme and plugin, and prints problems
--plugin add <name | git URL>Installs a plugin: github, linear, bitbucket, jira, slack, tokens, define, currency, contacts, shortcuts, cleanlinks, reveal, ai
--plugin listWhat's installed, and what else you can add
--try-plugin <id> [query]Runs one plugin once and shows its rows. Prints OK when it works
--import <files>Turns Raycast or Alfred exports into TOML: --import snippets.json >> config.toml
--mcpRuns the MCP server your coding agents use to search Euclid
--ai <prompt>Asks Apple's on-device model (macOS 26 with Apple Intelligence). --ai --check exits 0 when ready
--speed-budgetTimes every keystroke over 10,000+ items and fails when one is slow
