# lgtm.ninja

Company site for LGTM Ninja, plus the Euclid site at `/euclid/`. Plain static HTML, served by GitHub Pages from the repo root.

- `index.html`, `style.css`: the page
- `logo.svg`: the LGTM Ninja mark (also the favicon)
- `euclid.png`: Euclid's app icon
- `euclid/`: the Euclid site (lgtm.ninja/euclid/): landing, features, plugins, legal pages, clips. Links inside it are relative.
- `llms.txt`: agent index (points at the Euclid plugin guide)
- `CNAME`: custom domain for GitHub Pages
